# Torto Privacy Policy

Effective date: October 20, 2026

Torto is a local-first e-book reader. Torto does not require a Torto account and does not include advertising or analytics.

## Data stored on your device

Imported books, reading progress, highlights, annotations, settings, OCR results, and locally generated search indexes are stored on your device. You can remove this data by deleting books or app data, or by uninstalling Torto and choosing to remove its data.

Credentials such as API keys and WebDAV passwords are stored through the operating system's secure credential store when that facility is available.

## Optional third-party services

Torto only sends data to external services when you enable and configure a corresponding feature:

- AI chat, translation, semantic search, and metadata extraction may send selected book text, page images, or prompts to the AI provider you configure.
- PDF OCR may send PDF pages or page images to the OCR provider you configure.
- WebDAV synchronization sends books, reading data, and supported generated book data directly to the WebDAV service you configure.

Those providers process data under their own privacy policies. TortoTech does not operate an intermediary service for these requests and does not receive their contents.

## Network access and updates

The Microsoft Store edition receives updates through Microsoft Store. Other desktop editions may check Torto's public GitHub releases for updates. Torto may also access remote resources that are explicitly referenced by a book or requested by you.

## Feedback and feature requests

When you submit feedback, Torto sends your description, selected report type, app version, operating system version, window size and display scale to TortoTech's feedback service, which creates a **public GitHub Issue**. Reports opened from the reader also include the book's original title, authors, languages, format and layout, the current chapter/book-relative location when available, and reader layout and translation settings. In focus mode, available source node identifiers and ranges for the active unit are included; the paragraph text is not automatically attached. You can review the included information before submitting. Opening the feedback dialog alone does not send a report.

Complete books, screenshots, logs, API keys, account details, highlights and chat history are not automatically attached. Any personal information you enter in the description will be public. A pending submission is saved locally so retries can reuse the same report. The service retains the request identifier, content hash, submission state and Issue link to prevent duplicates; it does not retain the description or book metadata in its database. The published report is held by GitHub under its own policies. Contact the repository maintainers to request removal of a published report.

## Data retention and deletion

Outside feedback you explicitly submit, reading data is not sent to or retained by TortoTech. Data held by a third-party provider is subject to that provider's retention policy. You can delete local Torto data from the app, from its application-data directory, or by uninstalling the app and removing its data.

## Changes and contact

Material changes will be published in this document. For privacy questions, open an issue at <https://github.com/TortoTech/torto/issues>.

# Torto 隐私政策

生效日期：2026 年 10 月 20 日

Torto 是一款本地优先的电子书阅读器。Torto 不要求注册 Torto 账号，也不包含广告或分析追踪。

## 保存在设备上的数据

导入的书籍、阅读进度、高亮、批注、设置、OCR 结果和本地生成的搜索索引均保存在你的设备上。你可以通过删除书籍或应用数据，或者卸载 Torto 并选择清除应用数据来删除这些内容。

API Key、WebDAV 密码等凭据会在系统支持时通过操作系统的安全凭据存储进行保存。

## 可选的第三方服务

只有当你主动启用并配置相应功能时，Torto 才会向外部服务发送数据：

- AI 对话、翻译、语义搜索和元数据提取可能会将所选书籍正文、页面图片或提示词发送给你配置的 AI 服务商。
- PDF OCR 可能会将 PDF 页面或页面图片发送给你配置的 OCR 服务商。
- WebDAV 同步会将书籍、阅读数据及受支持的书籍衍生数据直接发送到你配置的 WebDAV 服务。

上述服务商会依据各自的隐私政策处理数据。TortoTech 不为这些请求提供中转服务，也不会收到请求内容。

## 网络访问与更新

Microsoft Store 版本通过 Microsoft Store 获取更新。其他桌面版本可能会检查 Torto 的公开 GitHub Release。Torto 也可能访问书籍中明确引用或由你主动请求的远程资源。

## 问题反馈与功能请求

提交反馈时，Torto 会将你填写的描述、反馈类型、应用版本、操作系统版本、窗口尺寸及显示缩放发送至 TortoTech 的反馈服务，由服务创建**公开的 GitHub Issue**。从阅读页打开的反馈还会附带原书书名、作者、语言、格式与版式，以及可获取的当前章节、书内相对位置、阅读版式和翻译设置。专注模式下还会附带可获取的当前聚焦单元的原文节点标识与范围，不会自动附带段落正文。提交前可以查看附带信息；仅打开弹窗不会发送反馈。

应用不会自动附带整本书、截图、日志、API Key、账号信息、高亮或聊天记录。你自行填写在描述中的个人信息会被公开。尚未确认结果的提交会保存在本地，以便重试时核对同一份反馈。服务端保留请求编号、内容哈希、提交状态及 Issue 链接来防止重复提交，不在数据库中保留描述或书籍元数据。已发布的反馈由 GitHub 按其自身政策保存；如需删除公开反馈，请联系仓库维护者。

## 数据保留与删除

除你主动提交的反馈外，阅读数据不会发送给 TortoTech，TortoTech 也不会保留这些数据。第三方服务商持有的数据受其自身保留政策约束。你可以在应用内、应用数据目录中，或通过卸载应用并清除其数据来删除本地 Torto 数据。

## 政策变更与联系

重要变更会发布在本文档中。如有隐私问题，请在 <https://github.com/TortoTech/torto/issues> 提交 Issue。
