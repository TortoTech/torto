# 阅读 AI 请求调度

桌面与 Android 使用 `crates/app-core/src/reading_ai.rs`，共同决定模型请求的准入、优先级、并发、取消与超时。UI 宿主负责提供原文快照和阅读需求、接收结果及重排页面；桌面的异步重排与 Android 的位图发布仍由各自适配层负责。

## 执行规则

- 结构识别、正文／目录翻译、图表／公式备注分别占用三个通道，每个通道最多一个请求，总计最多三个。等待队列最多 32 项，重复任务合并；高优先级任务可替换队列中的低优先级任务。
- 阅读位置稳定 200 ms 后开始新请求。可见正文翻译、可见结构识别优先；增强与后台任务等待主要请求安静 250 ms，目录翻译也避开正在执行的可见正文任务。
- 新的可见任务需要同一通道时，可以中断旧的后台任务。仅仅滑出屏幕不会立即取消已经发送的付费请求；手势、选区及弹窗暂停新请求和页面发布。停止、退到后台或配置失效时取消旧任务。
- 每个实际模型任务共用 180 秒执行上限，排队时间不计入。底层 HTTP 服务保留原有重试预算，调度器不叠加模型重试。取消及抢占不记为模型失败；结构／增强失败保留基础内容，翻译失败保留原文并提供重试。

## 批次、缓存与发布

`reading_ai/batching.rs` 从原文及目录边界生成固定语义批次，保留相邻上下文；两端使用同一个规划器，不随每次滚动重新切割输入。请求范围外的预取只预热结构识别，正文翻译限于宿主提交的可见范围及其前瞻范围。

Android 不单独配置“预处理下一页”，与桌面一样自动按当前目录小节的固定批次预热结构，并由共享调度器保证可见任务优先和空闲准入。旧 Android `ai_prefetch` 偏好不再参与决策；未开启 AI 排版时不额外预热结构，翻译不会因为移除开关而扩大到整个小节。预取结果不移动阅读位置，不预处理未访问的其他小节。

同时开启识别与翻译时，先识别原文结构，再翻译分类后的内容，整批就绪后一起发布。大表格即使拆成多次 HTTP 请求，也不逐份替换可见正文。每次成功传输的译文仍可缓存，取消后能够复用；并行批次写缓存时合并已有条目，避免互相覆盖。

图表和公式备注在基础正文之外独立生成，不阻塞阅读。结果安装前校验书籍、原文修订、模型／端点和目标语言；页面回调另校验阅读状态版本。Android 按版本顺序发布通知，弹窗或手势期间收到的有效结果延后刷新，离屏结果只更新缓存。

Android 在采用结果时从当前显示的保留页面捕获聚焦来源及其屏幕坐标，重排后重新解析该来源，再恢复文字基线。长段落使用当前可见行的真实字形来源，不沿用旧逻辑页码或像素滚动偏移；无可选文字的媒体使用来源几何。翻译、自动排版、分句、图表／公式切换、媒体索引更新和 AI 设置刷新共用 `android-bridge/reflow.rs`，基础识别和译文不会各自重排一次。网络等待期间用户已经翻到的新位置优先于发起请求时的位置。

Android 的原文快照缓存最多保留 16 节，软预算 8 MiB；单个超大当前节可独立保留。准备中的任务和完成记录有界，空闲后不轮询模型队列。模型网络等待不持有阅读会话锁，Kotlin 的操作互斥只保护短命令和页面采用，不等待模型响应。

## 配置保存

Android 的 AI 排版、翻译与阅读助手详情页暂存编辑，在返回或关闭页面时自动保存，不显示保存按钮或管理提供商入口。按字段计算当前用途的修改，进入串行操作队列后合并到最新配置，避免覆盖其他页面或较早保存任务的结果；未改动的字段跟随最新配置刷新。自定义目标语言保留最后输入，空白输入沿用之前的有效语言。保存后共用原有配置加载、取消失效任务和保持阅读位置的处理；编辑过程中不反复落盘或重启模型任务。

## 验证

共享调度测试覆盖队列顺序、稳定后抢占、取消／失效／任务中止释放通道、有界等待队列和各类请求超时。桥接测试使用本地模型服务，验证模型等待期间仍可读取页面、正文与目录术语表、取消后恢复、重复需求不重复发送、配置变化拒绝旧结果及图表／公式备注通知。长引用样本另暂停后台批次响应，再跳到其来源，核对完成后自动接续可见翻译，无需再触发一次手势。

Android instrumentation 使用 Release 原生库和隔离模拟器，核对实际 JNI 页面发布、图表切换、公式备注展开、目标语言切换及无重复头部进度条，不调用付费模型。

位置回归覆盖短／长原文、短／长译文与替换／双语的八种组合，以及分句、图表和公式切换；本地 HTTP 模型另暂停翻译响应，允许用户切换聚焦段落，再核对返回后的来源和屏幕位置。测试不向个人手机导入样本。
