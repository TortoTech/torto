## Feature

- Add an Android app with immersive reading, notes, translation, AI layout, cloud sync and reading statistics, available as separate ARM64 and x86_64 APKs.
- Add portable mode for Windows and macOS, keeping books and settings with the app when moving between computers.
- Install macOS updates from within the app, with automatic recovery if installation fails.
- Zoom original PDF pages using pinch gestures, shortcuts or compact controls in the bottom-right corner.

## Improvement

- Download default reading fonts automatically on Android, with a five-second notification offering to apply them without losing your reading position.
- Smooth mobile focus scrolling and section turns, and refine reader toolbars, settings, chapter-grouped notes and full-screen image previews.
- Fit complex tables to the reading area, limit preview width and recalculate layouts after translation; simplify formula symbol notes.
- Refresh the cloud library as books arrive and pace synchronization requests to reduce throttling.
- Preserve the visible passage when translation or AI layout results arrive, and reduce distracting loading indicators.
- Redesign completion pages with reading statistics and an explicit action to mark a book finished.
- Store API keys and sync passwords locally as plaintext to avoid repeated system authorization prompts; credentials remain excluded from cloud sync and diagnostic exports.

## Fix

- Prevent a Windows crash when scheduling AI layout and correct macOS update verification.
- Recover malformed table-of-contents destinations in source order and prevent section navigation from looping.
- Restore images affected by HTML/CSS sizing rules and correctly associate nearby figure captions and sources.
- Improve recognition of nested and image-based code examples, preserving literal markup without adding language badges to book content.
- Restore table/chart switching, translated list layout and optimized line breaking after sentence splitting.
- Return to the retained reading position when moving backward from the completion page, and prevent mobile navigation from freezing at the end of a book.
- Prevent database-lock errors when reading progress and cloud sync save at the same time.
