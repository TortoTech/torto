## Feature

- A centered end-of-book page shows reading time and lets you mark the book finished or return to your library.

## Improvement

- Focus-mode AI conversations include the selected passage's footnotes for more complete context.
- Sentence splitting uses normal line spacing while retaining each sentence's indent for a more compact reading layout.
- Footnote popups use consistent fonts and line breaking, improve English hyphenation, justification and long URL wrapping, and provide more space for text.
- Adjusted the reading toolbar height and icon sizes for a more compact layout.
- Reading history uses more compact dates and hides zero-duration labels.
- Thinking-level options now have Chinese labels, and new cloud-sync configurations default to cstcloud.

## Fix

- Keep the reading position stable when splitting paragraphs into sentences, and let you scroll through content that extends below the screen before moving on.
