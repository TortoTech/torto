## Feature

- Recognize common in-text citations automatically in Unified Layout, including author–year references with multiple works or years.
- Add Gitee as an alternative update source, with automatic release mirroring and verified installer downloads.

## Improvement

- Reduce installer size and simplify translation requests while preserving compatibility with previously translated content.
- Increase spacing around footnote markers and disable reasoning by default for AI layout requests.
- Place statistics navigation in the header and align the bookshelf search field with book covers below it.

## Fix

- Prevent formula placeholders from causing translation crashes or leaving cached paragraphs untranslated.
- Cover the header with the image preview backdrop and allow the preview shortcut to close an open preview.
- Handle minimized Windows windows safely and save crash reports in installed builds for troubleshooting.
